# Dependencies and licensing status

Original gateway/publisher/client code has no owner-selected license. Public distribution is blocked pending that decision and a complete review of applicable upstream obligations. This file does not grant a license or substitute for legal review.

`dependency-inventory.json` records exact versions from uv.lock, publisher/package-lock.json and clients/package-lock.json, lock hashes, available license expressions/fields, and paths to verbatim notice copies under `notices/`. `scripts/license_inventory.py` regenerates those records only from the frozen locks and matching installed package metadata/files. It does not infer a license for unavailable bytes. Conditional optional npm wheels/packages and image OS components remain explicit gaps. The current inventory includes the frozen MCP/client locks. Npm identities must match both the project lock and npm hidden installation receipt. Relevant upstream notice names are derived from the verified tarball, not merely the installed directory. Their verbatim bytes are copied directly from that artifact even if LICENSE/NOTICE is missing from node_modules; `installed_missing_notices` records such gaps. Installed copies, when present, must match. Accepted notice/package metadata bytes additionally match a local tarball whose SHA512 equals the lock integrity; missing cache artifacts remain explicitly unavailable. Receipt, package metadata, artifact and notice hashes are recorded. This verifies inspected bytes, not an upstream signature or distribution clearance.

Important observed families include Python/PSF; PostgreSQL/PostgreSQL License; Nginx/BSD-family; Node/MIT plus bundled components; uv/MIT or Apache2.0; Cube/Apache2.0; Python dependency licenses including MIT, Apache2.0, BSD-family, MPL2.0 and LGPL3.0; and separately licensed npm/browser bundles. The generated package inventory is authoritative for the inspected Python/npm artifacts; this prose is not a complete notice list.

The installed psycopg and psycopg-binary metadata reports LGPL3.0-only. Bundled binary libraries and container image packages must be inventoried from the actual built artifacts before any distribution claim. Preserve upstream source/notice links and any corresponding-source/relinking obligations identified by the review. Playwright's browser distribution has its own included notices; obtaining a browser does not license all content generically.

Exact image SBOMs, source provenance verification, CVE review and optional package notice completeness are release gates. A local build-ID/source-hash match proves which local output was used; it is not a signed upstream attestation or legal clearance.

Regenerate offline with `GATEWAY_NPM_CACHES=/absolute/npm-cache:/absolute/other-cache uv run --locked --offline python -m scripts.license_inventory`. Cache paths are explicit local inputs; generation performs no download or audit transmission. Lock changes require regeneration before an immutable release review.
